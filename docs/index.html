Features

Made for the everyday loop.

Prompt, render, look, tweak. The loop stays quick, and the node graph is there when you need it.

01 Models that work out of the box
  1. 01

    Models that work out of the box

    Drop a model into ComfyUI and it runs with its makers’ settings. Missing text encoders, VAEs and nodes download with one click, and the controls show only what the model uses.

    No model yet? Pick Krea 2, Flux.2 or SDXL, each in three sizes. The one that fits your computer is marked.

    Supported models
  2. 02

    Watch it render

    Previews stream in while ComfyUI works, resolving from a pixel mosaic into the final image. Queue the next one while you wait.

  3. 03

    Phone studio

    On a phone, the studio is laid out for your thumb. Prompt, browse, share and upscale from the couch while the computer renders.

    On your PC, open Settings › Connection and turn on “Open on other devices”. Set a studio password under “Signing in”, then scan the QR code with your phone and sign in. Both devices need to be on the same trusted network.

    Phone setup
  4. 04

    Your studio, over LAN

    Open HEISS UI in a browser on any other device on your local network: a laptop, tablet, phone or another desktop. Prompt, browse and upscale while your PC does the rendering, with the same models and gallery.

    On your PC, enable “Open on other devices” in Settings › Connection and set a studio password. Open the network address shown there on your other device, then sign in. Works over Wi-Fi or wired LAN on a network you trust.

    LAN setup
  5. 05

    Find it again

    Press ↑ in an empty prompt for recent prompts, or / to search the gallery by prompt, model or LoRA. Star the prompts and images worth keeping.

    Older ComfyUI, AUTOMATIC1111 or Forge folders can join the gallery where they are.

  6. 06

    Hidden

    A locked place for images you keep to yourself. Generate into it or hide anything later, and unlock it with Touch ID, Windows Hello or a password. While it’s locked, nothing shows.

  7. 07

    Upscale and compare

    Upscale any image in one click with SeedVR2, then drag across it to see what changed. An optional face detail pass (beta) redraws small faces first.

  8. 08

    Bring your own workflow

    Built something good in ComfyUI? Import its JSON and it turns into a clean set of controls, with your graph running underneath. The import review shows what each control is connected to, and you can change any of them.

    Workflow guide

Also

  • LoRA stacks

    Grouped by folder, stacked per run and saved per model family. A LoRA made for another model says so.

  • Reference and start images

    Flux.2 and Qwen-Image 2.1 edit from reference images. Other image models start from an image, with a slider for how much may change.

  • Zen mode

    A fullscreen prompt and the image, without the panels.

  • A trash for Delete all

    Delete all moves images to a trash you can restore for 30 days.

  • Sharing, with or without settings

    Shared and downloaded images can leave out the prompt, seed and workflow, on by default for Hidden. New PNGs can also carry them the way Civitai reads them Beta.

Runs on your computer, with no account and no telemetry. Updates are signed, and Hidden is encrypted on disk.

Install

Running in a few minutes.

You need ComfyUI. The download brings everything else, Node.js included. Your models stay in ComfyUI.

Also for

The macOS download is for Apple Silicon. Intel Macs can run it from source.

  1. 1

    Start ComfyUI

    It connects on its own when it runs on this computer, ComfyUI Desktop included. No ComfyUI yet?

    ComfyUI on another machine? Set its address in Settings › Connection.

  2. 2

    Unzip and start

    Unzip the download and double-click Start HEISS UI.

    • macOSThe first time, right-click it › Open.
    • WindowsExtract All first, into a plain folder rather than one synced by OneDrive.
    • LinuxRight-click the .desktop file › Allow Launching, or run the .sh.
  3. 3

    Open the studio

    It opens in the browser at localhost:8787. With no model yet, pick a first one and it downloads with everything it needs.

Updating later: Settings › About in the app.

Other ways to install

To follow main, or on an Intel Mac. Needs Node.js 20.9 or newer.

Terminal 
git clone https://github.com/tristmeister/HEISS-UI.git heiss-ui
cd heiss-ui
npm install
npm start

To update, git pull, npm install, npm run build.

Paste this into Claude Code, Codex or another coding agent that can use your terminal. It gets the right download, starts the app and checks that it reaches ComfyUI. Models only download if you ask.

Prompt 
Set up HEISS UI on this computer: https://github.com/tristmeister/HEISS-UI

1. Check my operating system and CPU. From https://github.com/tristmeister/HEISS-UI/releases/latest, download the matching zip: heiss-ui-<version>-windows-x64.zip, -macos-arm64.zip or -linux-x64.zip. Skip the plain heiss-ui-<version>.zip; that one is for in-app updates.
2. Unpack it into a plain folder, such as ~/HEISS-UI or C:\HEISS-UI (on Windows, not a folder synced by OneDrive). Node.js and all packages are inside, and the app updates itself from Settings › About.
3. Check that ComfyUI is running on this computer: http://127.0.0.1:8188, or http://127.0.0.1:8000 for ComfyUI Desktop. Either one connects on its own. If it isn't running, help me start my existing install. If I have none, tell me which one to get for my system and stop there.
4. Start HEISS UI with the launcher in the folder: Start HEISS UI.bat on Windows, .command on macOS, .desktop on Linux. It opens http://localhost:8787, or the next free port if 8787 is taken.
5. Check that the page loads, shows ComfyUI as connected and lists my models.

Only if I ask to run from source: check for Node.js 20.9 or newer, clone the repository, then run npm install and npm start.
Only if ComfyUI runs on another machine: set its address in Settings › Connection, or COMFY_URL in .env.

Don't download models unless I ask. Keep it on this computer: opening it to a phone or other devices is a switch in Settings › Connection, and only if I ask for it. If something fails, read the error and check ComfyUI's /system_stats and /object_info before changing anything.

FAQ

Fair questions.

Something missing? Ask on the board.

What is HEISS UI?

A local web front end for ComfyUI: a prompt box, a gallery and the settings the chosen model uses. ComfyUI still runs every job.

What do I need?

ComfyUI, and a graphics card or a Mac with Apple Silicon. ComfyUI runs every job, and the controls come from what it has installed; parts and node packs you download go into its own folders. No ComfyUI yet? Start HEISS UI and No ComfyUI yet? says which one to get. ComfyUI connects once it runs.

A graphics card with 8 GB runs SDXL and the compact Flux.2 Klein, 12 to 16 GB is comfortable, and 24 GB or more runs nearly everything. On a Mac, count the unified memory: 16 GB runs SDXL, 18 GB Flux.2 Klein and 48 GB Krea 2. What runs where has the details.

Which models work?

28 families out of the box, 21 for images and 7 for video, from SD 1.5 and SDXL to Flux.2, Qwen-Image, Krea 2 and Wan 2.2. Missing text encoders, VAEs and nodes download with one click. GGUF files run through the ComfyUI-GGUF nodes, which install with one click too, though that pack doesn’t load every family yet. Anything else runs as your own workflow. See the full list.

Does it do video?

Yes, marked Beta for now. Wan 2.1, Wan 2.2 5B, Wan 2.2 14B, HunyuanVideo 1.5 and MiniMax H3 run built in, no workflow needed, and Wan 2.2 14B and HunyuanVideo 1.5 also start from an image. Videos get their own gallery.

Can I bring my own workflows?

Yes, and for anything custom it’s the way to go. Build and test the graph in ComfyUI, export it (API or regular format) and drop it on the Workflow Gallery. The review shows which inputs follow the studio’s controls and marks the guessed ones, and you can change any of them before importing. The workflow guide covers the rest.

Why not use ComfyUI directly?

For building workflows, do. The node graph is great for that and less great for the everyday loop of prompt, wait, look, tweak. HEISS UI is for that loop, and your workflows come along.

Where do my images go?

Into your normal ComfyUI output folder, with gallery details in a local data folder next to the app. No account, no cloud in between, no telemetry.

What’s Hidden?

A separate, encrypted place for images you keep to yourself, opened from the lock in the dock. Images, prompts and settings are encrypted on your computer, and nothing shows while it’s locked. It keeps things out of casual view on a shared computer. It isn’t a forensic guarantee.

Can I use it from my phone?

On your own network, yes. On the PC running HEISS UI, open Settings › Connection and turn on Open on other devices. Set a studio password under Signing in, then scan the QR code with your phone and sign in. Laptops, tablets and other desktops can open the network address in their browser too. The phone gets a studio for your thumb: prompt, browse, share and upscale.

Updates, installs and other admin stay at the computer unless you allow them for signed-in devices. For HTTPS, add your own certificate in the same place. Only open it on a network you trust.

Where does HEISS UI come from?

It started as a fork of J-AI Studio by Jasper. The idea of a prompt-first front end for ComfyUI, and a big part of the foundation, are his work. HEISS UI takes it in its own direction from there. Go give the original a star too.

Why “HEISS”?

Heiß is German for hot. Hence the steaming cup.

HEISS UI is a simple, open source frontend for ComfyUI, meant to just work. SDXL, Flux.2, Qwen-Image, Wan 2.2 and 24 more model families run on your own computer, with no graph to wire and no hassle.
