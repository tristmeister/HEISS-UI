Features

Made for the everyday loop.

Prompt, render, look, tweak. HEISS UI keeps that loop quick and saves the node graph for when you need it.

01 Bring your own workflow
  1. 01

    Bring your own workflow

    Built something good in ComfyUI? Export it as an API workflow, map the inputs you care about and import it. It becomes a clean set of controls, with your graph running underneath.

    Workflow guide
  2. 02

    Controls that fit the model

    HEISS UI reads what your ComfyUI has installed and only shows what the selected model uses. Switch from an image model to a video one and the controls follow.

  3. 03

    Watch it render

    Previews stream in while ComfyUI works, resolving from a pixel mosaic into the final image. Queue the next one while you wait.

  4. 04

    Private Vault

    Flip the Private switch next to the prompt and that generation is encrypted, prompt and settings included. It stays behind your password.

  5. 05

    Upscale and compare

    Run any image through an upscale workflow, then drag across it to see exactly what changed.

Install

Running in a few minutes.

You need Node.js 20+ and a working ComfyUI install. Your models stay right where they are.

  1. 1

    Start ComfyUI

    HEISS UI looks for it at 127.0.0.1:8188. If yours lives somewhere else, you'll set that in a second.

  2. 2

    Clone, build, start

    Terminal 
    git clone https://github.com/tristmeister/HEISS-UI.git heiss-ui
cd heiss-ui
npm install
npm run build
npm start

    ComfyUI on another port or machine? Copy .env.example to .env and set COMFY_URL.

  3. 3

    Open it

    Go to 127.0.0.1:8787. Your models, samplers and VAEs show up on their own. Custom workflows go in under Settings → Workflows.

Paste this into Claude Code, Codex or any coding agent that can use your terminal. It checks your setup, installs everything and confirms the app can reach ComfyUI. Model downloads only happen if you ask for them.

Prompt 
Install and run HEISS UI from GitHub: https://github.com/tristmeister/HEISS-UI

Please do the full local setup for me:

1. Check whether Node.js 20+ is installed.
2. Check whether ComfyUI is installed and running at http://127.0.0.1:8188.
3. If ComfyUI is not running, help me start my existing ComfyUI install. Do not download models unless I explicitly ask.
4. Clone https://github.com/tristmeister/HEISS-UI into a normal projects folder.
5. Run npm install.
6. Copy .env.example to .env only if configuration changes are needed.
7. Set COMFY_URL to my ComfyUI URL, usually http://127.0.0.1:8188.
8. Run npm run build.
9. Start the app with npm start.
10. Open http://127.0.0.1:8787 and verify the app can reach ComfyUI, detect models, and load the gallery.
11. For future updates, use Settings -> Update, or run git pull, npm install, and npm run build.

Keep everything local. Do not expose HOST=0.0.0.0 unless I ask for phone or LAN access. If something fails, read the error, check ComfyUI /object_info and /system_stats, and fix the setup instead of guessing.

Updating later: Settings → Update inside the app, or git pull, npm install, npm run build.

FAQ

Fair questions.

Something missing? Ask on GitHub.

What is HEISS UI, exactly?

A local web front end for ComfyUI. You get a prompt box, a gallery and only the settings that matter for the model you picked. ComfyUI still runs every job. HEISS UI is a nicer place to drive it from.

Can I bring my own workflows?

Yes, and for anything custom it's the way to go. Build and test the graph in ComfyUI, export it in API format, add the control mapping and import it under Settings → Workflows. It shows up as soon as the nodes it needs are installed. The workflow guide walks through the mapping.

Why not just use ComfyUI directly?

For building workflows, you should. The node graph is great for that and less great for the everyday loop of prompt, wait, look, tweak. HEISS UI is for that loop, and your workflows come along.

Do I still need ComfyUI installed?

Yes. HEISS UI doesn't ship its own runtime or models. It reads what your ComfyUI has installed (checkpoints, samplers, schedulers, text encoders, VAEs) and builds its controls from that.

Which models work?

The common image, checkpoint and video setups work out of the box. For a model that needs custom nodes or special wiring, get it running in ComfyUI first and bring it over as your own workflow.

Does it do video?

It does, as long as your ComfyUI has video nodes and a workflow for them. Images and videos get their own galleries.

Where do my images go?

Into your normal ComfyUI output folder. HEISS UI keeps its gallery metadata in its own local data folder. No account, no cloud in between, and your prompts and images stay on your machine.

What's the Private Vault?

An opt-in switch next to the prompt. Private generations get encrypted along with their prompt and settings and stay behind a password. Good for keeping things out of casual view on a shared computer, though it's not a forensic guarantee.

Can I use it from my phone?

On your own network, yes. Set HOST=0.0.0.0, allow the port through your firewall and open your computer's IP on your phone. Only do this on a network you trust.

Where does HEISS UI come from?

It started as a fork of J-AI Studio by Jasper. The core idea of a calm, prompt-first front end for ComfyUI, and a big part of the foundation, are his work. HEISS UI takes it in its own direction from there. Go give the original a star too.

Why “HEISS”?

Heiß is German for hot. Hence the steaming cup.
