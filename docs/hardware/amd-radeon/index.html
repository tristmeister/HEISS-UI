Short answer

Radeon RX 7000 and RX 9000 cards run ComfyUI on Windows through ComfyUI Desktop or the AMD portable build, both on AMD’s ROCm, and on Linux with ROCm 7.2. RX 6000 cards need a community build. What fits is set by the memory, as on NVIDIA; the speed, and how well ComfyUI juggles memory, still trail.

An RX 9070 XT or 7900 XTX is a good ComfyUI card. An RX 6600 is a project.

ComfyUI Desktop added ROCm for Windows in version 0.7.0, in January 2026. Its Windows requirements now name NVIDIA and AMD cards.

ComfyUI Desktop has run on AMD cards under Windows since January 2026, on ROCm 7.1.1 [1][2]. ComfyUI also publishes a portable build for AMD, ComfyUI_windows_portable_amd.7z, and its README lists experimental Windows and Linux wheels for RDNA 3, 3.5 and 4 [3].

RX 7000 and 9000 on Windows.

  1. 1

    Update the Radeon driver

    When ROCm support launched, AMD recommended its ROCm 7.1.1 preview driver. Take the current Adrenalin driver, or a newer ROCm driver if AMD offers one for your card.

  2. 2

    Install ComfyUI Desktop

    From comfy.org/download. Or unpack the AMD portable build into a plain folder such as C:\ComfyUI if you’d rather keep everything together.

  3. 3

    Leave headroom

    ComfyUI’s newer memory handling isn’t on for most AMD setups yet, so leave room for Windows. AMD’s own guide uses --reserve-vram 3 on 16 GB cards and --reserve-vram 2 --lowvram on 12 GB cards [4]. In Desktop that’s Reserved VRAM (GB) and VRAM management mode in the server settings.

  4. 4

    Pick fp16, bf16 or GGUF files

    Radeon cards don’t compute fp8. fp8 files still save memory, since ComfyUI unpacks them as it goes, but not time. nvfp4 files are for NVIDIA’s RTX 50 series.

On Linux.

Linux is still where Radeon cards run ComfyUI best, and ROCm has supported them there for longer [8]. Install PyTorch for ROCm, then ComfyUI as usual:

Terminal
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2

AMD’s guide for the RX 9000 series adds these environment settings and flags for stability [4]:

Terminal
export PYTORCH_HIP_ALLOC_CONF=expandable_segments:True
python main.py --reserve-vram 3

ComfyUI’s README adds PYTORCH_TUNABLEOP_ENABLED=1, which can speed things up after a very slow first run.

RX 6000 cards.

AMD’s ROCm doesn’t officially support RDNA 2 in ComfyUI’s builds. It works with workarounds:

  • Linux: start ComfyUI with HSA_OVERRIDE_GFX_VERSION=10.3.0 for the RX 6700 and 6600 families, as ComfyUI’s README says.
  • Windows: the community ComfyUI-ROCm build supports GCN 5 through RDNA 4 [9]. ZLUDA builds work too, more slowly.
  • RX 6600: ComfyUI picks bf16 on this card, which runs about half speed. A fix was proposed in September 2026 [7]; keep ComfyUI updated.

DirectML also runs ComfyUI on any Radeon, slowly. It reports a placeholder amount of memory, so tools that read ComfyUI’s memory can’t tell what fits.

Two differences: nvfp4 files are NVIDIA-only, and without ComfyUI’s dynamic memory handling a model that just fits on NVIDIA may need a size down on AMD.

Video on Radeon.

Wan 2.2 runs, with more friction than on NVIDIA. On an RX 7900 GRE with 32 GB of RAM, the high-noise half of Wan 2.2 14B stayed in RAM while the low-noise half loaded, and the system ran out [10]. Start with Wan 2.2 5B, keep 64 GB of RAM for the 14B, and add --reserve-vram.

Intel Arc.

ComfyUI publishes a portable build for Intel cards (ComfyUI_windows_portable_intel.7z), and on Linux and Windows it runs on PyTorch’s own xpu builds. The Arc B580 has 12 GB and ran SDXL at about 4 it/s in the benchmark thread [5]. Use the 12 GB guide for what fits.

Questions.

Does ComfyUI Desktop work with AMD cards now?

Yes. Since version 0.7.0 in January 2026, ComfyUI Desktop runs on Radeon cards under Windows through AMD’s ROCm. The RX 7000 and 9000 series are the supported ones.

ZLUDA or ROCm?

ROCm, where your card supports it: it’s AMD’s own stack and what ComfyUI builds for. ZLUDA builds are for older cards on Windows, and they’re slower.

Why is my RX 6600 so slow?

ComfyUI chooses bf16 on that card, which it computes about half as fast as fp16. A fix was proposed in September 2026. Keep ComfyUI updated.

Does DirectML work?

It runs, slowly, on almost any Radeon. It reports a placeholder amount of memory, so nothing can tell what fits. ROCm is the better route on any card that supports it.

RX 9070 XT or RTX 5070 Ti for ComfyUI?

Both have 16 GB. The 5070 Ti computes fp8 and nvfp4, gets ComfyUI’s newer memory handling, and most guides and custom nodes assume NVIDIA. The 9070 XT works well on ROCm. For ComfyUI alone, NVIDIA is the easier road.

HEISS UI

It reads Radeons too.

HEISS UI is a prompt box and a gallery on top of your ComfyUI, on NVIDIA, AMD, Intel or a Mac.

  • The model that fits your Radeon is marked. It reads the card’s memory from ComfyUI and marks the size that suits it. Everything else stays one tap away.
  • Out of memory? One tap. A run that runs out offers to free memory and try again, or to try again smaller with the same seed.
  • Drop in any model and it runs. It recognises the file, even renamed, and uses settings that fit it. No graph to wire.
  • Missing parts, shown first. Anything a model still needs is listed with its size and a button. Nothing downloads behind your back.
  • Runs on the ComfyUI you have. No second install. Your models, your output folder.
