Short answer

If you want today’s models without learning a node graph, HEISS UI on ComfyUI is the shorter path. Flux.2, Krea 2, Qwen-Image 2.1 and video run built in, each set up for you, missing pieces arrive in one click, and your old A1111 and Forge images join the same gallery.

If you live in A1111’s tabs, with inpainting, ControlNet, hires fix and X/Y/Z plots, Forge Neo keeps that interface going with current models. Plain A1111 stops at SDXL.

We make HEISS UI

Everything about Forge Neo, Forge, reForge and AUTOMATIC1111 here comes from their own docs and repositories, checked on 29 September 2026. Spot something out of date? Open an issue and we’ll fix it.

Pick HEISS UI if

  • You want today’s models, including Flux.2 Dev, Qwen-Image 2.1, HunyuanVideo 1.5 and MiniMax H3, without learning a graph.
  • You’d like each model recognised from its file and set up to run, renamed files included.
  • You want missing pieces listed with their sizes and fetched in one click.
  • You want your A1111 and Forge images in the same gallery, where they already are.
  • You generate from your phone, or want an encrypted place for private images.

Pick Forge Neo if

  • You want the A1111 layout, tabs and extensions you already know.
  • You inpaint, sketch or use ControlNet every day.
  • You rely on hires fix, X/Y/Z plots or A1111’s prompt editing, like [cat:dog:0.5].
  • You’d rather not run ComfyUI at all.

Is A1111 dead?

It isn’t getting new features. AUTOMATIC1111’s last release is 1.10.1 from July 2024, its main branch hasn’t changed since, and the dev branch got a few install fixes in early 2026. It still runs SD 1.5, SDXL and SD3 Medium with the extensions you had, and people who only use SDXL fine-tunes keep it for that. It doesn’t run Flux, Qwen-Image, Krea 2 or any video model.

Forge, reForge, Forge Classic, Forge Neo.

The names are confusing, so here they are in order.

  • Forge by lllyasviel sped up A1111 and added Flux.1, NF4 and GGUF in 2024. Its last commit is from June 2025, and its one-click package still ships CUDA 12.1 with PyTorch 2.3.1.
  • reForge by Panchovix now points people to Forge Classic and Forge Neo in its own README, for stability.
  • Forge Classic and Forge Neo by Haoming02 are two branches of one repository. Classic keeps the older Forge base. Neo continues the Forge that had Flux, and it’s the one adding new models.

If a guide says “Forge” in 2026, it usually means Forge Neo.

New models, and how they arrive.

Forge Neo adds each model in its own code, and its README says exactly what’s in and what isn’t: Flux.2 Klein but not Flux.2 Dev, Wan 2.2 14B but not the 5B. Some models are recognised by name, so a Qwen edit model needs “qwen” and “edit” in its path. The list is long, and it keeps growing.

HEISS UI runs on ComfyUI, which usually supports a model on release day. Its built-in list covers 28 families, and anything else ComfyUI runs can come in as your own workflow. Models are recognised from their weights, so a renamed file still works. See the guides for Flux.2 Dev, Krea 2 and Qwen-Image.

Bring your old images.

In Settings › Library, add your A1111 or Forge output folder and those images join the HEISS UI gallery where they are, without copying. Search them with /, star the good ones. New PNGs can also carry their prompt and settings the way AUTOMATIC1111 writes them, so Civitai fills in an upload (beta, in Settings › Library).

Where Forge Neo is the better pick.

A full inpainting canvas, hires fix and X/Y/Z are where the A1111 line is ahead. Forge Neo has an inpainting canvas, sketch, soft inpainting, ControlNet with Union and LLLite models, hires fix, a refiner, X/Y/Z plots and A1111’s prompt editing. If those are how you work, stay with it.

HEISS UI now has quick inpainting (beta): hover a start or reference image, paint over the part to change and say what it becomes. Only that part is redrawn, with no extra nodes to install. Around it sit a start image with a Change from the reference slider for every image model, reference images for Flux.2 and Qwen-Image 2.1, and SeedVR2 upscaling to 2K or 4K inside each run, with an optional face detail pass. That covers a lot of everyday fixes. It isn’t Forge Neo’s canvas with sketch and soft inpainting.

What HEISS UI doesn’t do (yet)

  • No canvas, layers or outpainting. Inpainting (beta) is a quick brush on a start or reference image, not a full editor.
  • No ControlNet or IP-Adapter controls, except inside a ComfyUI workflow you import.
  • No hires fix and no X/Y/Z grids.
  • No LTX-2 video yet. HEISS UI recognises the files but doesn’t run them built in.
  • No engine of its own. On a Mac it runs ComfyUI through PyTorch’s Metal backend, where fp8 files load at full precision and save no memory.

Moving over from A1111 or Forge.

  1. 1

    Install ComfyUI

    ComfyUI Desktop on Windows with NVIDIA or on a Mac, the portable build with an AMD card, the manual install on Linux.

  2. 2

    Reuse your models

    ComfyUI’s extra_model_paths.yaml has an a111 section. Set its base_path to your stable-diffusion-webui folder and ComfyUI reads the same checkpoints, LoRAs and VAEs.

  3. 3

    Start HEISS UI

    Unzip it, double-click Start HEISS UI, and add your old output folder under Settings › Library.

Questions.

Is AUTOMATIC1111 still maintained?

Not with new features. Its last release is 1.10.1 from July 2024, and only a few install fixes landed on the dev branch in early 2026. It runs SD 1.5, SDXL and SD3 Medium, not newer models.

Is Forge dead?

The original Forge by lllyasviel stopped in June 2025. Forge Neo by Haoming02 continues it and releases often, with Krea 2, Flux.2 Klein, Z-Image, Qwen-Image and Wan 2.2 14B.

Forge Neo or ComfyUI?

Forge Neo if you want the A1111 interface with inpainting, ControlNet, hires fix and X/Y/Z. ComfyUI if you want every new model first and custom workflows. HEISS UI gives you ComfyUI’s models without the graph.

Can ComfyUI use my A1111 models?

Yes. Rename ComfyUI’s extra_model_paths.yaml.example to extra_model_paths.yaml, uncomment the a111 section and set base_path to your stable-diffusion-webui folder.

Can HEISS UI show my old A1111 images?

Yes. Add the output folder in Settings › Library and the images join the gallery where they are, without being copied.
