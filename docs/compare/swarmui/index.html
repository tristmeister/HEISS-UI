SwarmUI vs HEISS UI.

Short answer

If you already run ComfyUI, HEISS UI is the calmer pick. It uses the install you have, sets each model up for you, turns your own workflows into simple controls without extra nodes, and gives you a real phone studio and an encrypted Hidden space.

If you want one app that does nearly everything, with an image editor, ControlNet, grids, audio and several GPUs, SwarmUI covers more.

We make HEISS UI

Everything about SwarmUI here comes from its own docs and repository, checked on 29 September 2026. Spot something out of date? Open an issue and we’ll fix it.

Pick HEISS UI if

  • You already have ComfyUI, Desktop, portable or manual, and want to keep using it as it is.
  • You want each model ready to prompt, with settings that fit it, turbo builds included.
  • Your own ComfyUI workflows should become simple controls without adding special nodes.
  • You want Wan 2.2 14B’s two halves set up for you.
  • You generate from your phone, or want fewer controls on screen.
  • You want a locked, encrypted place for private images.

Pick SwarmUI if

  • You want a full image editor and ControlNet in the same app.
  • You compare settings, models or LoRAs side by side with the Grid Generator.
  • You need LTX-2, audio models or the widest model list around.
  • You run several GPUs or machines, or share one install with a team.
  • You like wildcards and advanced prompt syntax.

Only in HEISS UI

  • Your ComfyUI, as it is. Nothing reinstalled, no second copy to keep updated.
  • Workflows without special nodes. Drop in the JSON, and a review shows what each control drives.
  • Wan 2.2 14B, paired for you. Both halves downloaded and set up together.
  • A phone studio. Made for one thumb, with its own sign-in.
  • Hidden. An encrypted place for private images, opened with Touch ID, Windows Hello or a password.

Or share the models

Both can read the same model files. Swarm’s Basic Usage guide shows how to point its Model Root at a ComfyUI models folder, and HEISS UI sees whatever your ComfyUI sees. Nothing needs to be downloaded twice.

Both run ComfyUI. The question is which one.

SwarmUI’s Generate tab builds a ComfyUI workflow from your settings and runs it. So does HEISS UI. The difference is where that ComfyUI comes from.

Swarm installs and starts its own ComfyUI by default, and keeps it with its other files. You can add an existing install as a backend, but its Basic Usage guide says that isn’t recommended for most users. HEISS UI never installs ComfyUI. It connects to the one you have, on this computer or another, and ComfyUI keeps your nodes, models and outputs where they are.

That also means HEISS UI doesn’t update ComfyUI for you. You update it when you choose, through Comfy Desktop or ComfyUI-Manager.

Settings for each model.

Swarm picks a model’s preferred resolution and applies some model-specific tweaks, and its Model Support docs list the parameters to use for each family, for example CFG 1 for Z-Image Turbo. For Wan 2.2 14B you set the high-noise model as the base and the low-noise model as a refiner with the StepSwap method.

HEISS UI sets starting values drawn from the official ComfyUI templates and model cards when you pick the model: sampler, scheduler, steps, CFG, shift and size. A file named like a Turbo, Lightning or DMD2 build gets few-step settings. For Wan 2.2 14B, the setup lists the low-noise half as a companion file and downloads it with the rest. Back to recommended undoes whatever you changed.

Your own workflows.

In Swarm, the Comfy Workflow tab gives you the full graph, and the Simple tab turns a saved workflow into a form once you add SwarmInput nodes for the inputs you want. In HEISS UI you export the workflow from ComfyUI as it is and drop it on the Workflow Gallery. The prompt, size, seed, steps, CFG, sampler, scheduler, denoise, frames and start image are connected for you, guesses are marked, and you can change any connection before importing.

Phone and privacy.

Swarm has a Mobile layout in its user settings. HEISS UI’s phone studio is its own layout: the gallery edge to edge, one Describe… pill, long press for Share, Upscale, Star, Hide or Delete, and the phone’s share sheet. Other devices sign in with a studio password, admin stays at the computer, and HTTPS works with a certificate you already have.

HEISS UI also has Hidden, an encrypted place for images you keep to yourself, unlocked with Touch ID, Windows Hello or a password. It keeps things out of casual view. It isn’t a forensic guarantee.

Where Swarm is the better pick.

Swarm has an image editor with inpainting, ControlNet, segment-based detail passes, the Grid Generator for comparing anything against anything, wildcards and a rich prompt syntax. It runs across several GPUs and machines, supports teams on one install, and has a documented API. Its model list is longer, including LTX-2 and audio models. If those are part of your week, Swarm is the better home.

What HEISS UI doesn’t do (yet)

  • No canvas, layers or outpainting. Inpainting (beta) is a quick brush on a start or reference image, not a full editor.
  • No ControlNet or IP-Adapter controls, except inside a ComfyUI workflow you import.
  • No hires fix and no X/Y/Z grids.
  • No LTX-2 video yet. HEISS UI recognises the files but doesn’t run them built in.
  • No engine of its own. On a Mac it runs ComfyUI through PyTorch’s Metal backend, where fp8 files load at full precision and save no memory.
  • No multi-GPU scheduling or shared team installs.

Trying HEISS UI next to Swarm.

  1. 1

    Have a ComfyUI running

    HEISS UI connects to a ComfyUI on port 8188 or 8000 automatically. If you only have Swarm’s built-in one, install ComfyUI Desktop or the portable build.

  2. 2

    Share the model folder

    Add Swarm’s model folder to ComfyUI’s extra_model_paths.yaml, or point Swarm at ComfyUI’s, so both see the same files.

  3. 3

    Start HEISS UI

    Unzip it and double-click Start HEISS UI. Pick a model and it lists anything that model still needs.

Questions.

Is SwarmUI a ComfyUI front end?

Yes. SwarmUI uses ComfyUI as its main backend and includes the full node graph in its Comfy Workflow tab. By default it installs its own copy of ComfyUI.

Can SwarmUI use my existing ComfyUI?

Yes, as a self-starting backend pointed at your ComfyUI’s main.py. Swarm’s own docs say that isn’t recommended for most users. HEISS UI always uses the ComfyUI you already run.

Does HEISS UI download text encoders and VAEs like Swarm?

Yes. Pick a model and its setup lists the missing text encoder, VAE, companion files and node packs, each with a Download or Install button and its size. Get all fetches the lot.

Which one has more features?

SwarmUI has more tools: an image editor, ControlNet, grids, wildcards, multi-GPU support and more models. HEISS UI has fewer controls and a few things Swarm doesn’t: your existing ComfyUI as it is, workflows without special nodes, a phone studio and Hidden.

Are both free?

Yes. Both are free and open source under the MIT licence.
